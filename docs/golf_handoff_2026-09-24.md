## 로컬 확인 방법

실행 중인 API/앱은 재시작해 메모리 캐시를 비운다. 프로젝트 루트 PowerShell:

```powershell
.\venv\Scripts\python.exe -B scripts\golf_db_status.py
.\venv\Scripts\python.exe -B -m unittest discover -s tests -p test_golf_import_policy.py -v
```

13개 정책 테스트: 기존 값 보존, 조건부 후보 보관, 출처 URL/인용 일치, 오래된 조사 재사용 방지, 요금 만료, 동일 입력 재실행, 원자적 저장/백업.
상태 스크립트는 DB 쓰기/외부 조사 없이 현재 집계, 기본 조건검색, 네 골프장 상세정보를 확인한다.

웹 UI는 기존 `run_dev.bat`(Next.js/FastAPI), 기존 Streamlit UI는 `run.bat` 사용. 두 개를 동시에 실행해 같은 포트를 중복 점유하지 않는다. 실행 파일 자체는 변경하지 않았다.
이름 검색에서 기흥/라데나/링크나인을 열고 위 번호·요금·출처를 확인한다. 주중/주말 전환으로 그린피 변화 확인. 조건검색은 우선 조건 없이 시작하고 지역/예산을 하나씩 적용한다. 정보 미확인 제외 시 결과가 줄어드는 것은 데이터 부족일 수 있으므로 무조건 필터 오류로 판단하지 않는다.
