# ZIP:ON — Polygon 없이 정상 동작하는 서비스로 전환하는 개발 계획 (2026-11-07)

**계획서이며 아직 구현하지 않았다.** 운영 DB 변경·배포·main 병합 없음. 기존 분석 결과와 코드(정규화 v2, 중복 레이어 근거, 매칭 분석 스크립트)는 유지하고, 경계 확보·SHP 매칭 고도화는 일시 중단한다.

## 0. 원칙
1. **구역 경계를 주장하지 않는다.** 위치는 대표좌표(849/1,190건)이며, 지도·문구 모두 "대표 위치", 거래는 "인근 추정(반경 N m)"으로만 표시한다. "구역 내부"라는 표현은 쓰지 않는다.
2. **경계가 생기면 끼워 넣을 자리는 남긴다.** `boundary_status`, `connections.trades.zone_matching`, `relation` 값(INSIDE_VERIFIED_BOUNDARY)은 그대로 두되 기본값은 비활성.
3. **PR #2 재사용:** 대시보드(지도 65/35, 모바일 시트, 마커·클러스터), 8단계 타임라인, 3시나리오 시뮬레이터, 탭 구조, `FeatureStatusCard`, `connections` 구조를 그대로 쓴다. 새 화면을 만들지 않고 "미연동" 카드를 실제 기능으로 교체한다.

## 1. 핵심 과제 A — 실거래 연동 (Polygon 없이)
| 단계 | 내용 | 재사용 | 승인 |

| A2 | 스키마 설계(문서·마이그레이션 초안만): `trade_transactions`(원자료, `source_hash` 멱등), `trade_locations`(지오코딩 캐시·정확도), `development_project_trade_links`(`relation`: **SAME_LOT / NEAR_ESTIMATED / LOCATION_UNKNOWN**, `radius_m`, `distance_m`, `method`) | `docs/zipon_phase2_3_plan` §3.3 | 스테이징 적용은 별도 승인 |

| A4 | API: `/development/projects/{id}/trades?radius=100|300|500&months=24&type=` (기본 24개월, 장기 추이용 월 집계는 별도 뷰) | 상세 API 캐시·마감 패턴 | 배포 승인 |
| A5 | 화면: 실거래 탭의 미연동 카드 → 거래 목록(계약일·금액·면적·층·건축연도·위치 정확도 배지), 반경 선택, 추이 차트. 지도 거래 마커는 후속 | `TradesTab`, `FeatureStatusCard`, `zipFormat` | 배포 승인 |
- 미확인 위험: 유형별 지번 공개 범위, 지오코딩 성공률(로컬 키·VWorld/NAVER 키 필요), 분양권·입주권 필드. A1 결과가 나오기 전에는 매칭률을 약속하지 않는다.

## 3. 핵심 과제 C — 거래·권리 확인(사전진단)
| 단계 | 내용 |
| --- | --- |
| C1 | 규칙 표 설계: 입력(현재 단계·기준일, 투기과열지구/조정대상지역 여부, 토지거래허가구역 여부, 조합설립인가·관리처분인가 일자, 매수 예정일) → 출력 3단계(제한사항 미확인 / 추가 확인 필요 / 법적 제한 또는 위험요소 확인) + 근거 조항·기준일·추가 확인 항목 |
| C2 | 규제 데이터: 규제지역·토지거래허가구역은 고시 기준일과 함께 **수동 관리 표**로 시작(출처 URL 필수), 자동화는 후속 |
| C3 | 엔진은 순수 함수 + 단위 테스트(법 조항별 사례), AI 설명은 엔진 결과를 풀어 쓰는 별도 계층. "거래 가능/안전" 단정 금지 유지 |
| C4 | 화면: 거래가이드 탭의 "미연동" 카드를 결과 카드로 교체, `connections.rights_engine` 상태를 서버가 결정 |
- 법률 검토(전문가 확인)가 반영 전 필요하다.

## 4. Polygon 없는 화면 정리 (작은 변경, PR #2 위에서)
- 지도: 대표 위치 마커 + 선택 시 반경 원(100/300/500m, "인근 추정" 범례). 기존 120m 원 안내 문구와 통일.
- 문구: "구역 안·밖" → "대표 위치 기준 반경 내 거래(추정)". 경계 관련 미연동 행은 "경계 정보는 제공하지 않음(대표 위치 기준)"으로 정리.
- 테스트: "구역 내부" 문구 부재, 반경 선택값 100/300/500만 허용, CLOSED 기본 숨김.

## 5. 우선순위와 일정(제안)
