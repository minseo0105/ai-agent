# 검색 지원 범위와 다음 보강 순서

## 이번 수정

조건/AI 문장검색은 수도권·충청권·강원권 추천 Pool을 사용한다. 입력 영역에 이를 명시하고 결과의 '전국' 표기를 제거했다. 제주·영남·호남 검색 결과가 없을 때 단순히 조건을 넓히라는 설명 대신 지원 범위 밖임을 안내한다. 전라도/경상남도/경상북도 등의 정식 지역명도 처리한다.
직접 찾기는 추천 범위와 별개로 등록된 골프장을 조회한다. 미확인 조건은 기본 제외되며 결과에서 포함할 수 있다는 실제 동작에 맞게 설명을 수정했다. 후기 기반 특징은 아직 확정 검색 필터가 아님을 안내한다.

## 보강 우선순위

1. **검색 정확성**: 입력에서 실제 적용한 조건과 미지원 조건을 구분한다. 2인, 연습장+PAR3, 후기 특징을 조용히 무시하는지 추가 회귀 시나리오로 점검한다. 부대비용 미확인인데 완전한 총액처럼 표시되는 문제, 최신 보강값과 오래된 충실도 배지의 불일치도 남은 작업이다.
2. **243개 추천 대상의 기본정보**: 2026-09-24 집계 기준 공식 URL 28곳, 전화 89곳, 그린피 표 125곳, 캐디 팀요금 107곳, 카트 팀요금 103곳이 미등록이다. 정보가 존재하더라도 기간/고객/인원/코스 조건과 근거를 재검증해야 한다. 예약가가 변동형이면 고정 가격을 만들어 채우지 않는다.
3. **기존 후기 후보 검증**: 649개 출처 후보와 235개 특징 후보를 우선 재사용한다. 골프장·코스/홀 일치, 원문 문맥, 날짜, 광고, 작성자 중복, 반대 의견을 검토한다. 독립된 최근 후기 2명 이상의 검토 근거가 쌓이면 '넓다는 후기 경향'으로 표시하고, 확정 제원과 분리한다. 원문 일부만 확보했거나 날짜가 없으면 보류한다.
4. **시설 조합**: 공식 근거가 있는 시설을 먼저 상세 화면에 표시한 후 데이터 충실도를 보고 필터를 공개한다. 시설 없음(false)과 미확인(null)은 구분한다.
5. **지역 확대**: 영남/호남/제주를 단순히 옵션에 추가하면 빈약한 데이터가 추천에 섞인다. 해당 지역의 운영 상태/홀수/위치/요금 근거를 먼저 검토한 뒤 Pool 포함 기준을 통과시켜 확장한다.

이 문서는 향후 작업 순서다. 위 항목 전체가 구현 완료된 것은 아니다. 이번 변경은 지원 범위 안내·결과 설명·지역 별칭 처리이며 DB 값과 기존 기능은 유지한다.
기존 전체 정보 1·7월, 요금 4·10월 갱신 일정은 변경하지 않았고 추가 유료 조사도 실행하지 않았다.
