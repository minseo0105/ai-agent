# MONEY Phase 7.1 — 예상 이자 불일치 수정 및 배포

## 실제 원인

사용 중인 로컬 체험 원장을 읽기 전용으로 조사해 체험일 2026-10-23, 통장 잔액 14,250원, 이번 주 입금된 과거 용돈 이자 3,150원을 확인했다. 기존 `TrialLedger.reward_items()`는 이 입금을 통장에서는 포함하고 예상 이자의 원금에서는 차감했다. 따라서 (14,250−3,150)×10%=1,110원이 표시됐다. 저금통 이자를 용돈 이자에 합친 오류나 100원 단위 입력·절사 오류는 아니었다.

## 수정

런타임 수정은 `services/moneyon_trial.py` 한 파일이다. 진행 중 주차의 용돈 이자 원금을 동일 기준일의 통장 거래 합계로 통일했다. 과거 주차에서 확정되어 새 주에 입금된 이자는 현재 쓸 수 있는 잔액에 포함한다. 과거 주차의 확정 원금·금액과 지급 기록은 `trial_closings` 및 `trial_rewards`에서 그대로 읽는다. 주차의 종료일 제외 조건, 1원 미만 절사, 부모 출금/아이 입금, 고유 주차·유형의 중복 지급 차단은 변경하지 않았다.

소비 실험 API는 이미 동일한 항목의 `base`에서 소비액을 빼므로 API 변경 없이 같은 원금을 사용한다. 지급 후 새 주의 원금이 늘어나는 것은 지난주를 재정산하는 것이 아니며, 지난주 지급 금액은 그대로 고정된다.

디자인·메뉴·색상·폰트·카드 배치·3D 이자니 이미지·프런트엔드 소스는 변경하지 않았다. 기존 검증본과 주요 UI 파일 및 PNG의 바이트 일치를 확인했다. AI LAB 포털과 다른 에이전트도 수정하지 않았다.

## 수정 전후

| 상태 | 통장 잔액 | 이자 원금 | 예상 용돈 이자 |
|---|---:|---:|---:|
| 수정 전 실제 재현 | 14,250 | 11,100 | 1,110 |
| 수정 후 | 14,250 | 14,250 | 1,425 |
| 이후 3,000원 소비 | 11,250 | 11,250 | 1,125 |

고정된 1,425원을 화면에 넣지 않았다. 실제 용돈 지급·과거 이자 승인·소비 거래를 생성해 재현했다. 저금통 이자는 별도의 금고 원금·정책으로 계산된다. 예상/마감 확정/지급 완료 상태와 실제 지급 금액을 구분한다.

일반 가족 모드의 부모 설정 정책(신규 적격 용돈·금리·상한)은 의도적으로 유지했다. 10%·상한 10,000원 설정에서 신규 용돈 14,250원→이자 1,425원, 소비 후 1,125원 및 조기 승인 차단을 확인했다. 일반 모드를 공개 Space에 새로 노출하지 않았다. 공개 서비스는 기존과 같이 체험 전용이다.
