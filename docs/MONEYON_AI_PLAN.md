## 1. 기능별 화면 위치 · 데이터 흐름 · 필요한 키

공통 흐름(세 기능 같음):

```
[버튼] → POST /api/moneyon/trial/ai/{feature}  (X-Moneyon-Trial 헤더로 내 통장 확인)
   서버: ① 내 장부에서 '사실'만 계산(합계·카테고리별·주차별·이자) ← 숫자는 코드가 계산, AI가 계산하지 않음
         ② 이름·메모·통장 이름 없이 {금액, 카테고리, 날짜, 계산 결과}만 Claude에 보냄
         ③ Claude 스트리밍 → SSE로 브라우저에 한 글자씩 → 끝나면 금지 표현 검사
         ④ 4초 안에 첫 글자가 없거나 오류·거절·검사 실패 → 준비된 결과로 대체
[화면] "꿀벌이 생각 중…"(점 3개 애니메이션) → 글자가 써지듯 표시 → 끝에 "AI가 작성했어요" 배지
```

### 원칙 구현

- **이름 없이**: AI 입력은 서버가 만든 JSON만. `note`(쓴 곳 메모)·통장 이름·별명은 넣지 않는다. 카테고리는 고정 목록(간식·학용품·장난감·선물·저금 등). 시연 데이터의 아이 이름도 화면에만.
- **아이 눈높이**: 시스템 지시 — 초등 저학년이 읽는 쉬운 말, 한 문장 30자 안팎, 어려운 금융 용어는 풀어서(이자 = "모아 둔 돈에 붙는 보너스").
- **금지**: 상품·카드·앱 추천, 광고 문구, 대출·투자 권유, 비교로 아이를 깎아내리는 말("○○보다 못해"), 무서운 표현. STOCK:ON의 `safety.py` 방식(정규식 목록) + 머니온용 목록(`가입하세요`, `추천`, `할인`, `이벤트`, `카드`, `대출`, `투자`, `○○은행 상품` 등). 스트리밍이 끝난 뒤 검사 → 걸리면 화면의 글을 **준비된 결과로 부드럽게 교체**(페이드).
- **자유 입력 차단**은 DEMO_READINESS 3절(목표 코치는 슬라이더·프리셋만, AI에 자유 문장 안 보냄).

### 시연 요구사항

- **실시간 생성**: 버튼 → "꿀벌이 생각 중…"(최대 4초) → 스트리밍(한 글자씩, 1분당 갱신 아님 — SSE `delta` 이벤트를 바로 그림).
- **대체(타임아웃 4초 / 전체 15초)**: ① 시연 데이터면 **미리 만든 AI 결과**(시연 전날 같은 프롬프트로 생성해 저장 — AI가 쓴 글이 맞으므로 배지 "AI가 작성했어요 · 미리 준비") ② 그 밖의 데이터면 **규칙 기반 문장**(배지 없이 "꿀벌 기본 편지"). 대체도 글자가 써지듯 같은 속도로 보여 준다(화면 흐름 동일).
- **배지**: AI 결과 끝에 "✨ AI가 작성했어요"(작게, 탭하면 "숫자는 앱이 계산했고 문장은 AI가 썼어요. 틀릴 수 있어요" 설명).
- **시연 모드**: 첫 화면 "시연 데이터로 시작" 버튼(`?demo=1`이거나 관리자 스위치 `MONEYON_DEMO_ENTRY=1`일 때만 보임) → 서버가 고정 시나리오(4주 기록: 용돈 5,000원/주, 간식·학용품·선물, 저축통장 "자전거" 목표 50,000원)를 내 체험 통장에 채움. 사람마다 각자 복사본(서로 안 섞임).

## 2. 모델 선택과 예상 비용

시연은 **첫 글자까지 시간**이 가장 중요하다(청중이 버튼을 누르고 기다리는 시간). 숫자는 코드가 계산하므로 AI는 짧은 글쓰기만 한다.

| 후보 | 단가(입력/출력, 100만 토큰) | 예상 장점 | 예상 단점 |
|---|---|---|---|
| **Claude Haiku 5.5** | $0.10 / $0.50 | 가장 빠름·저렴. effort `low` + 생각 끄기(`thinking` disabled는 effort high 이하에서 허용)로 첫 글자 지연 최소 | 거절 시 서버 대체 모델 기능 없음(→ 우리 쪽 대체 결과로 처리) |
| Claude Sonnet 5.5 | $2 / $10 | 문장 품질·지시 준수(STOCK:ON 비교에서 Opus와 비슷) | 20배 비쌈, 첫 글자 약간 느림 |

**잠정 추천**: 편지·코치 = Haiku 5.5, 부모 리포트 = Haiku 5.5 우선, 비교에서 대화 팁 품질이 부족하면 Sonnet 5.5.

**호출당 예상**(입력 약 1,200토큰 = 지시 600 + 사실 600, 출력 약 300토큰):
- Haiku 5.5: 1,200×$0.10/M + 300×$0.50/M ≈ **$0.0003**
- Sonnet 5.5: 1,200×$2/M + 300×$10/M ≈ **$0.0054**

**시연 1회 예상**: 30명 × 3기능 × 평균 2번 = 180회 → Haiku 약 **$0.05**, Sonnet 약 **$1.0**. 리허설·부하 테스트(실제 AI 소량)까지 합쳐도 Haiku 기준 $1 미만. 하루 상한은 `MONEYON_AI_DAILY_USD=3`(DEMO_READINESS).

**실제 비교 방법**(STOCK:ON과 같은 방식, 구현 후 11/1 전후 1회, 비용 약 $0.1):
1. 고정 체험 데이터 3종(① 아껴 쓰는 아이 ② 간식에 많이 쓴 아이 ③ 저금을 시작한 아이) × 3기능 × 2모델 = 18회, 같은 입력·같은 지시.
2. 기록: 실제 `usage` 토큰·비용, **첫 글자까지 시간**, 전체 시간, 금지 표현·숫자 오류(코드 계산값과 다른 숫자) 건수, 문장(나란히 표).
3. 합격: 첫 글자 p95 2초 이하, 숫자 오류 0, 금지 표현 0, 아이 말투 자연스러움(사람이 읽고 표시).
4. 결과를 이 문서에 표로 붙이고 모델 확정 → 확정 모델로 시연 데이터용 "미리 준비" 결과를 생성·저장.
