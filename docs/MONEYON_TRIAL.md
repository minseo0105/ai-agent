# MONEY Phase 4 완료 보고 — 샘플 통장 자유 체험

## 1. 구현 구조

`/moneyon` 첫 화면은 **바로 체험하기**, **부모님과 직접 시작하기**를 제공한다. 기존 AI LAB 코드 로그인은 ‘기존 가족으로 시작하기’에 유지했다. 기존 부모 PIN·자녀 등록·권한·가족 원장을 변경하지 않았다.

| 파일 | 역할 |
| --- | --- |
| `services/moneyon_trial.py` | 방문자별 시드, 비밀 토큰 검증, 가상 날짜, 추가 용돈, 원자적 초기화 |
| `api/moneyon_trial.py` | 체험 전용 API와 입력 검증, 세션·자녀·세대 검증, 캐시 금지 |
| `api/main.py` | 체험 라우터 등록 |
| `web/src/app/moneyon/TrialExperience.tsx` | 탭 세션 복원, 금액 입력, 날짜·승인·초기화 확인 UI |
| `MoneyOn.tsx`, `ChildExperience.tsx`, `child.css` | 진입 선택, 기존 3개 메뉴 재사용, 짧은 결과 안내와 금액 애니메이션 |
| `tests/test_moneyon_trial.py` | 원장·API·동시성·격리·롤백 33개 검사 |
| `tests/test_moneyon_trial_browser.cjs` | 실제 Chrome 19개 시나리오와 세 화면 크기 캡처 |

기존 `Ledger`, `MockBankingAdapter`, 계좌 분개, 소비 분류, 목표, 보상 계산을 재사용한다. 기존 금융 핵심 파일 `services/moneyon.py`, `moneyon_accounts.py`, `moneyon_banking.py`, `moneyon_demo.py`, `api/moneyon.py`는 Phase 4에서 수정하지 않았다. 체험 전용 `TrialLedger`만 중첩 작업을 하나의 SQLite 트랜잭션에 묶는다. 연결은 ContextVar로 분리하고 중첩 범위는 SAVEPOINT를 사용한다.

## 2. 샘플 원장과 계산 검증

가상 시작일은 반복 재현 가능한 **2026-10-12**다. 모든 금융 거래와 잔액은 실제 Mock Ledger·계좌 분개에 기록한다.

| 현재 샘플 거래 | 통장 변화 | 저금통 변화 |
| --- | ---: | ---: |
| 지난 회차 부모 보상 | +1,500 | 0 |
| 이번 회차 용돈 | +50,000 | 0 |
| 문구 구매 | -5,000 | 0 |
| 간식 구매 | -3,000 | 0 |
| 저금통 이동 | -15,000 | +15,000 |
| 최종 확정 잔액 | **28,500** | **15,000** |

지난 보상을 임의로 입금하지 않는다. 2026-10-05 회차에 15,000원을 지급하고, 10%·최대 1,500원·이월 안 함 정책으로 10월 12일 실제 정산한다. 정산 시 원금 15,000원은 부모에게 반환되고 보상 1,500원만 남는다. 따라서 통장 전체 내역에는 이전 회차의 **+15,000원 지급과 -15,000원 반환**도 감사 이력으로 표시된다. 이번 회차의 50,000원 지급은 별도 실제 거래다.

이번 회차는 신규 용돈 50,000원에서 소비 8,000원과 저금통 이동 15,000원을 차감한 **27,000원**이 적격 잔액이다. 기존 `reward()`의 `min(27,000 × 10%, 800)` 결과가 **800원**이다. 예상 보상은 총 보유금액에 합산하지 않는다. 이월금·지난 보상·금고 잔액도 적격 잔액에서 제외한다. 신규 용돈의 10%가 한도 미만으로 내려가면 예상 보상이 즉시 감소한다.

부모 가상 계좌는 500,000원으로 시작하며 시드 후 **448,500원**이다. 모든 은행 이벤트의 분개 합계는 0이다. 저금통은 30,000원 목표의 50%로 시작한다. 보상은 **부모가 지급하는 교육용 보상**이며 은행 예금 이자가 아니다.

## 3. 직접 조작 가능한 기능

- **용돈 받기:** 홈에서 금액을 입력한다. 부모 출금과 자녀 입금은 같은 이벤트·트랜잭션으로 반영한다. 현재 회차에 추가로 받은 용돈은 동일 회차의 적격 금액에 반영한다. 새 회차는 기존 엔진으로 개설한다. 부모 잔액 부족 시 모두 롤백한다.
- **돈 썼어요:** 소비 항목·금액·카테고리를 입력한다. 같은 거래가 통장과 기입장·분류별 소비·예상 보상에 반영된다. 기존 가상 가맹점과 카테고리 수정도 사용할 수 있다.
- **저축:** 하단 저축에서 금액을 입력해 넣거나 꺼낸다. 통장과 금고를 함께 갱신하고 합계는 보존한다. 목표 달성률과 예상 보상도 기존 규칙으로 계산한다.
- **보상 체험:** 현재 예상 보상과 지급 이력을 표시한다. 날짜는 현재 가상일 이후, 2027-10-12까지 이동할 수 있다. 종료된 미정산 회차만 동의 체크 후 ‘부모 승인 시뮬레이션’으로 지급한다. 같은 요청 재전송은 한 번만 처리하고, 다른 요청으로 같은 회차를 다시 승인하면 거절한다. 종료된 회차가 미정산이면 소비와 다음 용돈도 차단한다.
- **결과:** 실제 영향을 받은 잔액·거래·분류·목표·보상만 갱신한다. 우루미는 한 문장으로 안내한다. 금액 변경에는 0.35초 애니메이션을 적용하고 reduced-motion 설정은 존중한다. 실패 시 확정 금액과 원장은 바뀌지 않는다.

어린이 하단 메뉴는 홈·통장·저축 세 개다. 체험에는 PIN 설정·가족 관리 등 복잡한 설정을 노출하지 않는다.

## 4. 체험 세션 격리와 유지 정책

| 조건 | 정책 |
| --- | --- |
| 새 방문 | 암호학적 난수 비밀 토큰과 방문자 전용 가족·자녀·계좌 생성 |
| 서버 저장 | 전용 SQLite `MONEYON_TRIAL_DB`; 기존 `MONEYON_DB`와 같은 경로 사용 거부 |
| 인증 | DB에는 토큰 SHA-256만 저장. 클라이언트는 `X-Moneyon-Trial` 헤더로 전달 |
| 권한 | 매 요청마다 현재 방문자와 자녀 ID 검사. 쓰기는 세대 번호도 검사 |
| 다른 방문자 | 조회·입금·소비·분류 수정·보상·초기화를 다른 방문자의 원장에 수행할 수 없음 |
| 같은 탭 새로고침 | sessionStorage 토큰으로 서버 원장·가상 날짜·세대를 다시 로드 |
| 일반 새 탭·새 브라우저 | 토큰이 없으므로 별도 체험 시작 |
| 탭 닫기 후 일반 새 접속 | 새 체험. 브라우저가 닫은 탭/세션을 복원하면 토큰도 복원될 수 있음 |
| 탭 복제·opener가 있는 탭 | 브라우저가 sessionStorage를 복사한 경우 같은 체험을 공유. 최신 거래·초기화는 새로고침하여 반영 |
| 유효 기간 | 생성 후 24시간. 새로고침으로 연장하지 않음. 만료 시 새 체험 안내 |
| 체험 나가기 | 해당 탭의 토큰 삭제. 기존 부모·AI LAB 로그인 토큰에는 영향 없음 |
| 캐시 | 체험 API는 `Cache-Control: no-store`, `Vary: X-Moneyon-Trial` |

전역 단일 데모 계좌를 사용하지 않는다. 기존 부모 인증 토큰을 만들거나 체험 토큰을 실제 부모 권한으로 승격하지 않는다. 체험 승인 API만 격리된 가상 부모 출금을 시뮬레이션한다. 기존 AI LAB 공개 범위 정책은 유지하므로 포털에서 모두에게 제공하려면 MONEY:ON 서비스가 공개 상태여야 한다. 이 작업은 공개 범위 설정을 변경하지 않았다.

## 5. 초기화 동작

홈의 ‘처음 상태로 돌아가기’는 **“체험한 내용만 처음 상태로 돌아가요.”** 확인 안내를 표시한다. 취소하면 아무것도 변경하지 않는다.

확인 시 한 `BEGIN IMMEDIATE` 안에서 새 샘플 가족·자녀·계좌·목표·날짜·회차·거래를 구성하고, 방문자 토큰의 연결을 새 공간으로 변경하며 세대를 증가시킨다. 중간 시드 실패는 전체 롤백한다. 같은 초기화 요청의 재전송은 새 공간을 중복 생성하지 않는다.

과거 체험 공간은 비활성 감사 이력으로 남지만 토큰으로 접근할 수 없다. 초기화 이전 자녀 ID와 이전 세대의 지연 요청은 거절한다. 초기화한 방문자의 토큰만 연결이 변경되며 다른 방문자와 기존 가족 DB는 변경하지 않는다.

재현 명령:

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -p test_moneyon_trial.py -q
node tests/test_moneyon_child_ui.cjs
cd web
$env:NEXT_BUILD_DIR='.next-moneyon'

cd ..
node tests/test_moneyon_trial_browser.cjs
```

브라우저 검사는 격리된 임시 DB를 사용하며 외부 은행·AI 서비스나 운영 DB를 호출하지 않는다. 테스트용 서버는 검사 후 종료한다.

## 8. 실행 방법과 미해결 사항

체험만 활성화하는 로컬 예시:

```powershell
$env:MONEYON_TRIAL_ENABLED='1'
$env:MONEYON_TRIAL_DB='data/moneyon/trial.sqlite3'
.venv/Scripts/python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

별도 터미널에서 기존 Next 개발 서버를 실행한다. 기존 가족 기능도 사용할 때는 Phase 2 문서의 `MONEYON_LOCAL_DEV=1` 등 기존 설정을 별도로 적용한다. 새 체험 플래그가 가족 API를 활성화하지는 않는다. 영속 파일 저장 경로가 필요하며 여러 서버 인스턴스가 독립 파일을 사용하는 구성은 지원하지 않는다.

요청한 체험 기능에 미완료 사항은 없다. 운영 배포는 수행하지 않았다. 운영 규모의 만료·비활성 감사 데이터 자동 삭제, 분산 저장소, 익명 생성 요청의 운영용 제한은 이번 로컬 프로토타입 범위에 포함하지 않았다. 만료는 접근 차단이며 서버 파일에서 24시간 후 자동 삭제한다는 뜻은 아니다. 브라우저의 복제·복원 정책으로 같은 토큰을 복사한 탭은 같은 방문자로 취급하고, 서로 다른 토큰의 방문자는 분리한다.

운영 DB 변경, 실제 은행 연결, 배포, Git push는 수행하지 않았다.
