## 결론
1. **서울플랜+ SHP와 국토부 정비구역 SHP는 모두 상업적 이용·변경 금지**라 현재 제약에서 대안이 되지 않는다.
2. 제한이 없거나 1유형인 후보 두 갈래: **(a) 서울 OA-23112/OA-20281 계열(제한 없음, 분기~일간 갱신)** — 속성·위치가 핵심이고 경계 폴리곤이 있는지는 필드 확인이 필요, **(b) 국토부 2D데이터 API(제1유형)** — 정비구역 레이어가 있고 서울 정비구역 사업명 속성이 있는지 확인 필요.
3. 확인 방법(승인·입력 필요):
   - 서울 오픈API 인증키(무료, 사용자 발급)로 OA-23112 응답 필드 1~5건 조회 — 키를 채팅에 붙이지 않고 로컬에서 실행하는 스크립트를 제공할 수 있다.
   - VWorld 레이어 목록·이용약관 확인: `www.vworld.kr`, `api.vworld.kr`를 이 환경에 허용했으나 프록시 반영 전이라 아직 접속되지 않았다(최대 약 1시간). 재시도 필요.
   - 제공기관 문의(`docs/zipon_shp_license_inquiry_2026-11-06.md`)에 "제한 없음 데이터셋(OA-23112)에 정비구역 경계가 포함되는지"를 추가해 문의.
4. 비용: 위 후보는 모두 무료(공공데이터포털·서울 열린데이터광장 활용신청, API 인증키 무료). 영리 이용 허락이 필요한 경우 제공기관 협의 비용은 미확인.
