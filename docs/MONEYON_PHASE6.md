# MONEY Phase 6 — 두 가지 교육용 보상

> 이 문서는 최초 로컬 구현 시점의 기록이다. 이후 100원 단위 제한과 전후 금액 안내를 보완하고 전용 Space 재배포·공개 검증을 완료했다. 최신 결과는 [최종 검증 보고서](MONEYON_PHASE6_FINAL.md)를 따른다.

## 적용 범위

로컬 체험 원장과 어린이 화면에 적용했다. 기존 가족 원장과 부모 기능은 기존 정책을 유지하며 자동으로 전환하거나 데이터를 마이그레이션하지 않는다. Hugging Face 재배포는 하지 않았다. 기존 AI LAB 및 다른 Space는 변경하지 않았다.

## 계산 정책

| 항목 | 계산 대상 | 체험 기본 주간 비율 | 주간 상한 | 지급 위치 |
|---|---|---|---|---|
| 용돈 아끼기 보너스 | 주간 마감 통장 잔액 | 1% | 800원 | 저금통 |
| 저금통 이자 | 주간 마감 저금통 잔액 | 2% | 2,000원 | 저금통 |

비율은 이번 구현의 체험 기본안이며 실제 은행 금리나 연이율이 아니다. 기존 정책 계산 함수로 원 단위 버림 및 상한을 적용한다. 통장과 저금통 원금을 각각 계산하므로 중복되지 않는다. 통장 잔액 기준이므로 이월된 사용 가능 용돈도 포함한다.

초기 원장은 통장 28,500원, 저금통 15,000원, 총 43,500원을 유지한다. 새 정책의 예상 금액은 각각 285원과 300원, 보조 합계 585원이다. 이전 단일 예상 보상 800원을 고정 표시하지 않는다. 지난 회차 지급 1,500원은 기존 이력으로 보존한다. 예상 보상은 총 보유금액에 포함하지 않는다.

월요일 시작, 다음 월요일 직전까지를 한 주로 취급한다. 원장의 거래 날짜로 마감 잔액을 재구성하고 주차별 정책을 저장한다. 마감 이후의 소비나 보상 지급이 지난 주 계산 원금을 바꾸지 않는다. 가상 날짜를 넘기면 용돈 입금이 없어도 새 주차를 만든다.

## 원장과 지급

`TrialLedger.reward_items`가 실제 거래 원장과 정책으로 두 예상 금액을 계산한다. `trial_rewards`에는 자녀·주차·보상 유형별 고유 키와 계산 원금, 지급액, 거래 ID, 지급 시각을 기록한다. 예상·승인 대기·지급 완료 상태를 구분한다.

종료된 주차만 체험 전용 부모 승인으로 지급할 수 있다. 두 항목을 각각 승인하며 부모 가상 계좌 출금과 저금통 입금을 같은 트랜잭션에서 처리한다. 같은 요청 재시도는 재지급하지 않고, 다른 요청 키로 중복 지급하면 거부한다. 두 항목 일괄 지급 도중 실패하면 전체를 되돌린다. 실제 은행 API나 운영 DB를 사용하지 않는다.

## 화면과 세션

홈에 내 용돈과 내 저금통을 분리하고 각 예상 금액을 표시한다. 합계는 작은 보조 정보다. 보상 체험에서 주차, 원금, 비율, 상한, 승인 상태와 실제 지급 이력을 별도로 확인한다. 저축 화면에서도 두 보상 거래를 구분한다. 우루미와 안내 문구로 부모의 교육용 보상이며 다음 주 예상 금액은 아직 내 돈이 아님을 설명한다.

기존 방문자별 capability와 독립 체험 원장, 탭별 sessionStorage 정책을 유지한다. 새 탭·다른 브라우저는 별도 체험이고 같은 탭 새로고침은 유지된다. 토큰 유효기간은 24시간이며 탭 종료 또는 서버 재생성 후에는 새 체험이 필요할 수 있다. 초기화는 새 샘플 원장을 원자적으로 연결하고 이전 원장은 접근 불가능한 감사 기록으로 보존한다. 가족 원장을 변경하지 않는다.

## 검증 결과

- MONEY Python 회귀 및 신규 테스트 115개 통과.
- 기존 어린이 UI 검사 28개 통과, TypeScript 검사 통과.
- 정적 내보내기 프로덕션 빌드 성공: Windows 로컬 의존성 junction 때문에 기본 Turbopack 빌드는 경로 제한으로 실패했고 동일 코드의 webpack 빌드로 검증했다.
- Chrome·Edge 실제 로컬 API 브라우저 검사 17항목 통과. 용돈·소비·저축, 각각의 예상액 변화, 별도 승인 및 저금통 지급, 새로고침, 탭/브라우저 격리, 초기화, API 노출 차단을 확인했다.
- 375px, 768px, 1440px 화면을 캡처하고 가로 넘침이 없음을 확인했다.
- 전체 AI LAB unittest 탐색은 347개 중 실패 6개·오류 24개로 통과하지 못했다. `bs4` 의존성 누락, Windows cp949 디코딩 오류 등이 관찰됐다. 이 결과는 MONEY 전용 115개 통과와 구분한다. 다른 에이전트 코드는 수정하지 않았다.

## 남은 확인

Linux Docker 빌드와 Hugging Face 실제 환경 검증은 재배포 승인 후 진행한다. 기존 가족 계정의 이원 정책 전환은 이번 체험 구현 범위에 포함하지 않는다. 체험 기본 비율·상한은 추후 정책 결정에 따라 변경할 수 있다. 현재 공개 Space는 기존 Phase 5 상태다.
