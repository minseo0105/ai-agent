무엇을 왜 설치하나요

설치할 것이 여러 개라 헷갈리기 쉽습니다. 먼저 각 도구가 어떤 역할인지 그림으로 잡고 시작합니다.

세 줄로 먼저 잡기 Claude Code는 월정액으로 내 자리 옆에 앉힌 개발자 직원입니다. 내가 말로 시키면 코드를 쓰고 실행해 줍니다.
Claude API는 완성된 앱에 달아 주는 외주 작가 전화번호입니다. 내가 없어도 앱이 전화해 일을 맡기고, 건마다 쓴 만큼 요금이 나갑니다.
Git은 작업의 자동 저장 일지입니다. 이 과정에서는 Windows용 Claude Code가 일할 때 쓰는 공구 상자라서 설치만 합니다.

도구비유왜 필요한가언제
Git도구 상자Windows에서 Claude Code가 파일을 다루고 명령을 실행할 때 내부적으로 씁니다. 우리가 직접 쓸 일은 없습니다.1회차
VS Code사무실 책상파일을 보고, 터미널을 열고, Claude Code와 대화하는 작업 공간입니다.1회차
Python엔진우리 앱은 Python으로 쓰입니다. 엔진이 없으면 설계도가 있어도 돌아가지 않습니다.1회차
Claude Code옆자리 개발자"이런 화면 만들어 줘"라는 말을 코드로 바꾸고, 설치와 실행도 대신합니다.1회차
Claude 구독개발자 고용 계약Claude Code에 로그인하는 데 씁니다. API 키는 필요 없습니다.1회차
Streamlit화면 틀버튼, 입력창, 표 같은 웹 화면을 Python 몇 줄로 만들게 해 줍니다.1회차
DART API 키자료실 출입증금융감독원 전자공시의 기업 개황·공시·재무 자료를 앱이 가져올 때 씁니다.2회차
Claude API 키작가 호출 번호완성된 앱이 스스로 Claude를 불러 보고서를 쓰게 할 때 씁니다. 쓴 만큼 크레딧이 차감됩니다.2회차
GitHub온라인 금고코드를 인터넷에 저장·공유하는 서비스입니다. 이 과정에서는 쓰지 않습니다.불필요

처음부터 Claude API를 발급받아야 하나요?

아니요.Claude를 쓰는 길은 두 가지입니다. Claude Code는 사람이 개발을 시킬 때 쓰고 구독 계정으로 로그인합니다. Claude API는 완성된 앱이 혼자 Claude를 부를 때 씁니다. 1회차는 화면만 만들기 때문에 구독만 있으면 되고, API 키는 앱에 "보고서 쓰기" 기능을 넣는 2회차에 발급합니다.

GitHub에 가입해서 저장해야 하나요?

아니요.Git(프로그램)과 GitHub(웹사이트)는 다릅니다. Windows에서는 Claude Code가 Git 프로그램을 필요로 해서 설치만 합니다. 결과물은 내 PC 폴더에 저장되므로 GitHub 가입은 필요 없습니다. 백업은 폴더를 통째로 복사하거나 압축해 두면 됩니다. 나중에 앱을 인터넷에 올려 동료와 같이 쓰고 싶을 때 GitHub를 배우면 됩니다.

설치 전 체크리스트

  • 설치 권한: 사내 PC는 프로그램 설치가 막혀 있을 수 있습니다. 미리 IT 담당 부서에 Git, VS Code, Python 설치를 요청해 두세요.
  • Claude 유료 구독(Pro, Max 또는 회사 Team 플랜) 계정의 이메일과 비밀번호

Git 설치 (Windows 사용자만)

  1. 아래 주소에서 Click here to download(64-bit Git for Windows Setup)을 내려받습니다.
    BROWSERGit for Windows 다운로드
    https://git-scm.com/downloads/win
  2. 설치 파일을 실행하고 모든 화면에서 기본값 그대로 Next를 누릅니다. 설정을 바꿀 필요가 없습니다.
  3. 설치가 끝나면 시작 메뉴에 Git Bash가 생깁니다. 열어 볼 필요는 없습니다. Claude Code가 알아서 씁니다.
Mac 사용자는 건너뛰세요Mac에는 필요한 도구가 이미 들어 있습니다. 나중에 "개발자 도구를 설치하시겠습니까?" 창이 뜨면 설치를 누르면 됩니다.

VS Code와 Python 설치

VS Code

  1. 아래 주소에서 Download 버튼을 누릅니다.
    BROWSERVS Code 다운로드
    https://code.visualstudio.com
  2. Windows: 설치 중 PATH에 추가와 "Code(으)로 열기" 메뉴 추가를 체크합니다.
    Mac: 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다.
  3. 메뉴를 한국어로 보려면 확장 아이콘에서 Korean Language Pack을 설치하고 재시작합니다.

Python

  1. Python 3.12 이상을 내려받습니다.
    BROWSERPython 다운로드
    https://www.python.org/downloads/
  2. Windows: 첫 화면 맨 아래 Add python.exe to PATH를 반드시 체크하고 Install Now를 누릅니다.
    Mac: .pkg 파일을 열어 안내대로 설치합니다.
  3. VS Code를 완전히 껐다 켜고, 메뉴 터미널 → 새 터미널을 연 뒤 아래를 입력합니다. 버전 번호가 나오면 성공입니다.
    TERMINALWindows
    python --version
    TERMINALMac
    python3 --version
"python은 인식되지 않습니다"가 나오면PATH 체크를 빠뜨린 경우입니다. Python 설치 파일을 다시 실행해 Modify로 들어가거나, 제거 후 체크하고 재설치하세요.

Claude Code 설치하고 로그인하기

  1. VS Code에서 Ctrl+Shift+X (Mac은 Cmd+Shift+X)로 확장 화면을 엽니다.
  2. Claude Code를 검색하고, 게시자가 Anthropic인 항목을 Install합니다. 신뢰 확인 창에서 Trust Publisher & Install을 누릅니다.
  3. 아무 파일이나 하나 연 상태에서 편집기 오른쪽 위 불꽃(Spark) 아이콘을 누르면 Claude Code 패널이 열립니다. 안 보이면 VS Code를 재시작합니다.
  4. 로그인 화면에서 Claude.ai Subscription을 고르고 브라우저에서 구독 계정으로 로그인합니다.
  5. 패널에 아래 문장을 붙여넣어 대답이 오는지 확인합니다.
    PROMPTClaude Code · 연결 확인
    안녕하세요. 저는 코딩을 전혀 모르는 비개발자입니다. 앞으로 설명은 쉬운 말로 짧게 해 주시고, 제가 직접 해야 하는 일이 있으면 단계별로 알려 주세요. 지금 이 PC에 Python과 Git이 설치되어 있는지 확인해 주세요.
"Claude Code on Windows requires git-bash" 오류가 뜨면Git 설치를 빠뜨렸거나, Git 설치 전에 VS Code를 켜 둔 경우입니다. 2장의 Git을 설치한 뒤 VS Code를 완전히 껐다가 다시 켜세요.
Claude Code가 무언가 하겠다고 물어보면파일 만들기, 프로그램 설치, 앱 실행 같은 요청이 옵니다. 무엇을 하는지 한 줄 설명을 읽고 허용하세요. 이해가 안 되면 "이게 무슨 뜻이에요?"라고 되물어도 됩니다.

프로젝트 폴더와 Streamlit 첫 화면

  1. 바탕화면에 report-agent 폴더를 만듭니다.
  2. VS Code 메뉴 파일 → 폴더 열기로 그 폴더를 엽니다. 신뢰 여부를 물으면 예, 작성자를 신뢰합니다를 누릅니다.
  3. Claude Code 패널에 아래 프롬프트를 붙여넣습니다.
    PROMPTClaude Code · 준비와 첫 화면
    지금 열린 폴더에서 "보고서 작성기" 웹 앱을 만들 거예요. 저는 비개발자라 단계마다 무엇을 했는지 한두 줄로 쉽게 알려 주세요.

1. 이 폴더 안에 Python 가상환경(.venv)을 만들어 주세요.
2. requirements.txt 를 만들고 streamlit 을 적은 뒤 가상환경에 설치해 주세요.
3. app.py 를 만들어 아주 간단한 첫 화면을 띄워 주세요.
   - 제목: "보고서 작성기"
   - 부제: "우리금융캐피탈 디지털전략부"
   - "안녕하세요! 화면이 잘 나왔습니다." 라는 문장 하나
4. 가상환경에서 앱을 실행하는 명령을 터미널에서 직접 실행해 주고, 브라우저 어느 주소로 들어가면 되는지 알려 주세요.
  4. 브라우저에 http://localhost:8501 화면이 뜨면 성공입니다.

앱 끄고 다시 켜기

앱을 끄려면 터미널을 클릭하고 Ctrl+C를 누릅니다. 다시 켤 때는 Claude Code에 "앱 다시 실행해 줘"라고 하거나 아래 명령을 씁니다.

보고서 작성기 화면 만들기

2회차에 진짜 데이터를 넣을 자리를 지금 만들어 둡니다. 데이터는 샘플을 쓰지만, 버튼을 누르면 보고서가 나오는 흐름은 완성본과 똑같습니다.

PROMPTClaude Code · 보고서 작성기 화면
app.py 를 "보고서 작성기" 화면으로 바꿔 주세요. 아직 외부 데이터나 AI는 연결하지 않고, 샘플 데이터로만 움직이게 해 주세요.

[입력 영역]
- 보고서 유형 선택: 거래처 현황 보고 / 여신 심사 참고 메모 / 경쟁사 비교
- 회사명 입력칸 (예시 문구: 예) 현대캐피탈)
- 검토 주제 (여러 줄 입력)
- "보고서 작성" 버튼

[결과 영역] 버튼을 누르면 아래 순서로 보여 주세요.
- 진행 단계 표시: 🔎 자료 찾는 중 → ✍️ 작성 중 → ✅ 완료 (1초씩 천천히)
- 샘플 보고서: 1. 요약 / 2. 기업 개황 / 3. 재무 현황(2개년 비교 표) / 4. 최근 공시 / 5. 시사점
- 맨 위에 "샘플 데이터입니다" 라는 노란 안내 상자
- 마크다운(.md) 파일로 내려받는 버튼

[공통]
- 화면 맨 아래 바닥글: "우리금융캐피탈 디지털전략부"
- 샘플 데이터는 sample_data.py 파일로 따로 빼 주세요. 2회차에 이 부분만 실제 데이터로 바꿀 거예요.

다 만들면 앱을 다시 실행해 주세요.
