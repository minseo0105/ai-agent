무엇을 쓰고, 왜 설치가 필요 없나요

이 과정은 프로그램을 하나도 설치하지 않습니다. 브라우저에서 웹 Claude Code에게 말로 시키면, Claude가 클라우드 컴퓨터에서 코드를 만들어 GitHub 창고에 올리고, Streamlit Cloud가 그 코드를 웹 화면으로 띄워 줍니다.

세 줄로 먼저 잡기 웹 Claude Code는 월정액으로 고용한 재택근무 개발자입니다. 브라우저 채팅으로 일을 시키면 회사(클라우드) 컴퓨터에서 코드를 써서 올려 줍니다.
GitHub는 코드를 보관하는 인터넷 서류함입니다. 개발자가 올린 초안을 내가 결재하면 원본에 반영됩니다.
Streamlit Cloud는 서류함의 코드를 가져가 웹 화면으로 띄워 주는 무료 가게 자리입니다. 주소만 있으면 휴대폰에서도 열립니다.

왜 VS Code를 설치하지 않고 웹으로 하나요?

사내 PC는 프로그램 설치가 막혀 있는 경우가 많고, 설치 오류로 첫 시간을 다 쓰기 쉽습니다. 웹 방식은 브라우저만 있으면 되고, 만든 앱이 처음부터 인터넷 주소로 열려 휴대폰에서도 바로 볼 수 있습니다. 대신 고친 결과를 보려면 결재(Merge) 후 1~3분을 기다려야 합니다. 내 PC에서 즉시 확인하며 만들고 싶다면 부록의 VS Code 방식을 쓰세요.

처음부터 Claude API를 발급받아야 하나요?

아니요.웹 Claude Code는 구독 계정으로 씁니다. Claude API 키는 완성된 앱이 혼자 Claude를 불러야 하는 2회차에 발급합니다.

GitHub 가입은 꼭 해야 하나요?

네.웹 Claude Code는 GitHub 창고에 있는 코드만 다룰 수 있고, Streamlit Cloud도 GitHub에서 코드를 가져갑니다. 가입은 무료이고 02장에서 함께 합니다.

C. 작업 환경(Default) 확인

연결이 끝나면 Pro·Max 플랜은 Default라는 작업 환경이 자동으로 만들어집니다. Team·Enterprise는 "Create your first cloud environment" 양식이 나오는데, 이름과 네트워크 설정은 그대로 두고 Create & finish를 누릅니다.

첫 화면 만들고 결재(Merge)하기

Claude에게 첫 화면을 만들게 하고, Claude가 올린 초안을 내가 검토해 원본에 반영합니다. 이 "초안 → 결재 → 반영" 흐름은 앞으로 계속 반복되니 이번에 확실히 익혀 둡니다.

초안·결재·반영이란

A. 첫 화면 요청하기

  1. claude.ai/code 왼쪽 위 + 새 세션을 누르고, 저장소 report-agent, 브랜치 main, 권한 Accept edits를 확인합니다.
  2. 아래 프롬프트를 붙여넣고 Enter를 누릅니다.
    PROMPT웹 Claude Code · 첫 화면
    이 저장소에 "보고서 작성기" 웹 앱을 만들 거예요. 저는 비개발자라 무엇을 했는지 한두 줄로 쉽게 알려 주세요.
이 앱은 Streamlit Community Cloud 에 배포해서 볼 거예요.

1. requirements.txt 를 만들고 streamlit 을 적어 주세요.
2. app.py 를 만들어 아주 간단한 첫 화면을 만들어 주세요.
   - 제목: "보고서 작성기"
   - 부제: "우리금융캐피탈 디지털전략부"
   - "안녕하세요! 화면이 잘 나왔습니다." 라는 문장 하나
3. 이 두 파일은 저장소 맨 바깥(최상위)에 두어 주세요.
4. 다 되면 변경 사항을 올리고(push), 제가 무엇을 확인하면 되는지 알려 주세요.
  3. Claude가 일하는 동안 진행 내용이 채팅에 나옵니다. 1~2분 뒤 "push 했다", "브랜치에 올렸다"는 말과 함께 멈추면 초안이 올라간 것입니다.
