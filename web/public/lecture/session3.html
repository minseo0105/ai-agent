배포란 무엇이고, 오늘 무엇을 준비하나요

지금까지 만든 앱은 내 PC 안에서만 열립니다. 배포는 앱을 인터넷에 올려서, 링크만 있으면 휴대폰이든 동료 PC든 어디서나 열리게 하는 일입니다.

도구비유오늘 하는 일
GitHub인터넷 코드 창고가입하고, 앱 파일 몇 개를 끌어다 올립니다.
Streamlit Cloud무료 가게 자리GitHub 계정으로 로그인해 창고의 앱을 실행시키고 주소를 받습니다.
Secrets가게 금고Claude API 키와 앱 비밀번호를 넣어 둡니다.
Claude API외주 작가 전화번호2회차에 받은 키를 그대로 씁니다. 사진을 읽고 코칭 글을 씁니다.

오늘의 준비물

  • 스코어카드 사진 2~3장을 휴대폰 사진첩에 넣어 오세요. 스마트스코어 공유 카드 캡처도 좋고 종이 스코어카드 사진도 좋습니다. 종이 카드는 PAR·거리·HDCP 줄이 보이게 찍으면 분석이 더 풍부해집니다.
  • 사진이 없는 분은 강사가 나눠 주는 예시 스코어카드를 씁니다.
  • 내가 자주 가는 코스의 홀별 PAR(선택): 종이 카드나 골프장 홈페이지 코스 안내에서 미리 적어 오면 좋습니다.
  • GitHub 가입에 쓸 이메일 (회사 메일 또는 개인 메일)
  • 2회차에 받은 Claude API 키와 콘솔 잔액 (잔액은 platform.claude.com의 Billing에서 확인)
  • 노트북과 같은 와이파이에 연결된 휴대폰
3회차는 새 폴더에서 시작합니다보고서 앱(report-agent)은 그대로 두고, 골프 코치는 golf-coach라는 새 폴더에서 만듭니다. 오늘 배운 배포 방법은 마지막에 보고서 앱에도 똑같이 쓸 수 있습니다.

휴대폰으로 내 앱 열어 보기

배포를 하기 전에, 2회차에 만든 보고서 앱을 휴대폰으로 열어 봅니다. 같은 와이파이 안에서는 열리고, 밖에서는 안 열리는 것을 직접 확인하는 것이 목적입니다.

  1. VS Code에서 report-agent 폴더를 열고 Claude Code에 "앱 실행해 줘"라고 합니다.
  2. 터미널에 주소가 두 줄 나옵니다. Local URL은 이 PC 전용, Network URL은 같은 와이파이의 다른 기기용입니다.
    TERMINAL앱 실행 시 나오는 주소 예시
      Local URL:   http://localhost:8501
  Network URL: http://192.168.0.23:8501
  3. 휴대폰을 노트북과 같은 와이파이에 연결하고, 휴대폰 브라우저 주소창에 Network URL을 그대로 입력합니다.
  4. Windows에서 "Windows 보안 경고: Python 액세스 허용" 창이 뜨면 개인 네트워크에 체크하고 액세스 허용을 누릅니다.
  5. 휴대폰에 보고서 앱이 뜨면 성공입니다. 이제 휴대폰의 와이파이를 끄고 LTE·5G로 다시 열어 보세요. 열리지 않습니다.
회사 와이파이에서는 안 열릴 수 있습니다회사망은 기기끼리 접속을 막아 두는 경우가 많습니다. 안 열리면 휴대폰 핫스팟에 노트북을 연결해 같은 방식으로 해 보세요.
그래서 배포가 필요합니다노트북이 꺼져 있거나, 다른 곳에 있거나, 동료가 쓰려면 앱이 인터넷 어딘가에서 계속 돌아가고 있어야 합니다. 오늘 후반부에 그 작업을 합니다.

골프 코치는 어떻게 분석하나요

AI에게 사진을 던지고 "분석해 줘"로 끝내면 숫자를 잘못 읽거나 계산이 틀려도 알 수 없습니다. 그래서 일을 네 단계로 나누고, 단계마다 가장 잘하는 쪽에 맡깁니다.

스마트스코어 공유 카드 읽는 법

  • 숫자는 타수가 아니라 파 대비입니다. 0은 파, 1은 보기, 2는 더블보기, 3은 트리플보기입니다. 전반 9홀 숫자를 더한 값에 36을 더하면 전반 타수가 됩니다.
  • 숫자 위 점(·)과 줄(¯)은 이 교안에서는 점 = 1퍼트, 줄 = 3퍼트로 봅니다(표시 없음 = 2퍼트). 앱 안 설정에서 바꿀 수 있게 만들어, 의미가 다르게 확인되면 고쳐 쓰면 됩니다.
  • 카드에는 홀별 PAR와 거리가 없습니다. 그래서 코스 PAR를 한 번 입력해 두는 기능을 넣습니다. 입력하지 않아도 기본 분석은 됩니다.

예시 카드 하나로 나오는 분석

항목예시 결과 (100타 · 전반 53 · 후반 47)계산 담당
성적 분포파 3 · 보기 6 · 더블 5 · 트리플 4코드
큰 실수 손실28타 오버 중 22타가 더블 이상에서 발생코드

골프 코치 앱 만들기

  1. 바탕화면에 golf-coach 폴더를 만들고 VS Code에서 파일 → 폴더 열기로 엽니다.
  2. 아래 준비 프롬프트를 Claude Code에 붙여넣습니다.
    PROMPTClaude Code · 준비
    지금 열린 폴더에서 "골프 스코어카드 코치" 웹 앱을 만들 거예요. 저는 비개발자라 단계마다 무엇을 했는지 한두 줄로 쉽게 알려 주세요. 나중에 인터넷에 배포할 앱이라 아래 규칙을 지켜 주세요.

1. Python 가상환경(.venv)을 만들고, requirements.txt 에 streamlit, anthropic, python-dotenv, pillow, pillow-heif, pandas 를 적어 설치해 주세요.
2. .env 파일을 만들고 ANTHROPIC_API_KEY= 와 APP_PASSWORD= 두 줄만 넣어 주세요. 값은 제가 직접 채웁니다.
3. .gitignore 를 만들어 .env 와 .venv 가 절대 올라가지 않게 해 주세요.
4. 키와 비밀번호는 get_secret(이름) 함수 하나로 읽게 해 주세요. 인터넷 배포 환경에서는 Streamlit의 st.secrets 에서, 내 PC에서는 .env 에서 읽고, st.secrets 가 없을 때 오류가 나지 않게 해 주세요.
5. 화면 꾸미기는 .streamlit 폴더를 쓰지 말고 app.py 안의 CSS로만 해 주세요. 배포할 때 올릴 파일을 app.py, requirements.txt 처럼 폴더 없이 몇 개로 단순하게 유지하고 싶어요.
6. 다 되면 제가 .env 에 무엇을 넣으면 되는지 알려 주세요.
  3. .env를 열어 2회차의 Claude API 키와, 앱 입장 비밀번호로 쓸 단어(예: golf2026)를 직접 넣고 저장합니다.
  4. 아래 본 프롬프트를 붙여넣습니다. 길지만 그대로 복사하면 됩니다.
    PROMPTClaude Code · 골프 코치 본체
    app.py 에 골프 스코어카드 코치를 만들어 주세요. Claude API(anthropic SDK)를 쓰고, 모델은 claude-sonnet-5-5 로 하되 파일 맨 위 설정값 한 곳에서 바꿀 수 있게 해 주세요. 휴대폰에서 주로 쓸 앱이라 화면을 세로 한 줄 배치로 만들어 주세요.

[0. 입장]
- 첫 화면에서 비밀번호를 묻고, get_secret("APP_PASSWORD") 와 같아야 다음 화면을 보여 주세요.

[1. 사진 올리기]
- 사진 올리기 칸(jpg, jpeg, png, heic). 휴대폰에서는 사진첩에서 고를 수 있어야 합니다.
- heic 이면 jpeg 로 바꾸고, 너무 큰 사진은 긴 변 1600px 정도로 줄여서 보내 주세요.

[2. AI가 사진 읽기]
- Claude 에게 사진을 보내 아래를 JSON 으로만 받아 주세요.
  · 카드 종류: "스마트스코어 공유 카드"(파 대비 숫자) 또는 "종이 스코어카드"(홀별 타수)
  · 골프장 이름, 코스 이름(전반/후반), 날짜, 총타, 전반·후반 타수
  · 18홀 각각: 파 대비 숫자, 숫자 위 기호(없음 / 점 / 줄)
  · 종이 카드라면 홀별 PAR, 거리, HDCP 도 있으면 읽기
- 사진 속 사람 이름은 읽지 말고 비워 두세요.
- 전반 합 + 36, 후반 합 + 36 이 카드의 전반·후반 타수와 맞는지 코드로 검산하고, 안 맞으면 노란 경고를 띄워 주세요.

[3. 사람이 확인]
- 읽은 결과를 18홀 표로 보여 주고 각 칸을 직접 고칠 수 있게 해 주세요 (st.data_editor).
- "기호 의미 설정"을 펼침 상자로 두세요. 기본값: 점 = 1퍼트, 줄 = 3퍼트, 없음 = 2퍼트. OB 나 벌타 등 다른 의미로도 바꿀 수 있게 해 주세요.
- "코스 PAR 입력"(선택) 펼침 상자: 전반 9홀, 후반 9홀 PAR 를 넣으면 이 세션 동안 기억해 주세요.
- 빠른 체크(선택): OB 개수(0~5), 가장 아쉬운 샷(드라이버 / 아이언 / 어프로치 / 퍼트 / 벙커) 버튼

[4. 코드로 계산] 아래 숫자는 반드시 Python 코드로 계산해 주세요. AI 에게 계산을 시키지 마세요.
- 총타, 전반·후반 타수와 차이
- 파 이하 / 보기 / 더블 / 트리플 이상 개수
- 더블 이상에서 잃은 타수와, 그것을 모두 보기로 막았다면 몇 타였을지
- 1퍼트·3퍼트 횟수와 퍼트로 잃은 타수 (기호 의미 설정 기준)
- 가장 나빴던 연속 3홀 구간
- PAR 를 입력했다면 파3 / 파4 / 파5 별 평균 파 대비 타수
- HDCP 가 있으면 어려운 홀(1~6) vs 쉬운 홀(13~18) 평균

[5. AI 코칭]
- 계산 결과 숫자와 빠른 체크 내용만 Claude 에게 보내고, 아래 형식으로 받아 주세요. 숫자는 받은 값만 쓰고 새로 지어내지 말라고 지시해 주세요.
  · 오늘 라운드 한 줄 평
  · 잘한 점 2가지
  · 타수를 잃은 핵심 원인 3가지 (근거 숫자 포함)
  · 다음 라운드 전략 3가지 (위기 홀 운영법 위주)
  · 연습장 30분 루틴 (시간 배분 포함)
- 말투: 50대 남성 골퍼에게 친근하게 조언하는 코치, 존댓말, 짧은 문장

[6. 결과 화면]
- 맨 위 큰 숫자 카드 3개: 총타 / 더블 이상 손실 타수 / 3퍼트 수
- 홀별 파 대비 막대그래프 (파는 초록, 보기 노랑, 더블 이상 빨강)
- 계산 표와 코칭 글
- "이 라운드 기록 내려받기(CSV)" 버튼과, 예전 기록 CSV 를 올리면 같은 코스의 지난 라운드와 비교해 주는 기능
- 맨 아래 바닥글: "우리금융캐피탈 디지털전략부"

다 만들면 앱을 실행해 주세요.
  5. 브라우저에서 비밀번호를 넣고, 노트북에 옮겨 둔 스코어카드 사진(또는 예시 카드)으로 끝까지 한 번 돌려 봅니다.
