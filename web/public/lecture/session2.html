API와 키는 무엇인가요

API는 프로그램끼리 정해진 방식으로 주고받는 창구입니다. 은행 창구에 번호표와 신분증을 내고 서류를 받는 것처럼, 우리 앱이 키를 보여 주고 자료나 작업 결과를 받아 옵니다.

1회차에 쓴 Claude Code와 오늘 받는 Claude API는 뭐가 다른가요?

Claude Code는 내가 개발을 시키는 도구라 구독으로 로그인했습니다. 오늘 만드는 앱은 수업이 끝난 뒤에도 앱이 혼자 Claude를 불러야 하므로, 앱 전용 출입증인 API 키가 필요합니다. 결제도 구독과 따로입니다.

Claude API 키 발급받기 (가입 → 충전 → 키 만들기)

2회차의 보고서 에이전트는 Claude API로 글을 씁니다. 키 발급은 A 가입 → B 크레딧 충전 → C 키 만들기 세 단계이고, 충전을 먼저 해야 키가 실제로 동작합니다.

아래 그림은 설명용으로 다시 그린 화면입니다메뉴 위치와 버튼 이름은 공식 문서 기준으로 맞췄지만, 색과 배치는 실제 화면과 조금 다를 수 있습니다. 번호(①②③)를 따라 누르면 됩니다.

A. 콘솔 가입하기 (5분)

  1. 브라우저에서 Claude 개발자 콘솔에 접속합니다. 예전 주소 console.anthropic.com으로 들어가도 같은 곳으로 연결됩니다.
    BROWSERClaude 개발자 콘솔
    https://platform.claude.com
  2. Google 계정으로 계속하거나, 이메일을 입력하고 메일로 온 로그인 링크를 누릅니다. 회사 메일로 가입하면 나중에 비용 처리가 편합니다.
  3. 처음 들어가면 이름, 조직(회사) 이름 같은 기본 정보를 묻습니다. 사실대로 입력하고 넘어갑니다.
claude.ai 구독과 다른 곳입니다1회차에 Claude Code에 로그인한 claude.ai 구독 계정과 이 콘솔은 결제가 따로입니다. 같은 이메일로 가입해도 콘솔에서 크레딧을 따로 충전해야 합니다.

키 보관함(.env) 만들기

키를 코드 안에 직접 쓰지 않고, 앱만 읽는 .env 파일에 따로 보관합니다.

PROMPTClaude Code · 키 보관함 준비
이제 이 앱에 API를 연결할 준비를 할게요. 1회차에 만든 화면 디자인은 그대로 유지해 주세요.

1. requirements.txt 에 anthropic, requests, python-dotenv, python-docx 를 추가하고 가상환경에 설치해 주세요.
2. .env 파일을 만들고 아래 두 줄만 넣어 주세요. 값은 비워 두세요. 제가 직접 채우겠습니다.
   ANTHROPIC_API_KEY=
   DART_API_KEY=
3. .gitignore 를 만들어 .env 와 .venv 가 절대 공유되지 않게 해 주세요.
4. 화면 사이드바(또는 아래쪽)에 "연결 상태"를 만들어 두 키가 채워져 있는지 ✅/❌ 로만 보여 주세요. 키 값 자체는 절대 화면에 나오면 안 됩니다.
5. 제가 .env 에 값을 어떻게 넣으면 되는지 알려 주세요.

왼쪽 파일 목록에서 .env를 열고 = 뒤에 키를 직접 붙여넣고 저장(Ctrl+S)합니다. 따옴표와 띄어쓰기는 넣지 않습니다. 저장 후 앱을 다시 켜서 연결 상태가 모두 ✅인지 봅니다.

DART 공시 데이터 연결하기

샘플 데이터 자리에 실제 공시를 넣습니다. DART는 회사 이름이 아니라 8자리 고유번호로 조회하므로, 이름을 번호로 바꾸는 단계가 들어갑니다.

PROMPTClaude Code · DART 연결
DART Open API를 연결해 주세요. 인증키는 .env 의 DART_API_KEY 를 씁니다. 화면 디자인은 그대로 유지해 주세요.

1. dart_api.py 파일을 새로 만들고 아래 기능을 넣어 주세요.
   - 회사 고유번호 목록: https://opendart.fss.or.kr/api/corpCode.xml 에서 압축 파일을 받아 풀고, 회사명 → 고유번호(corp_code) 표를 data 폴더에 저장해 두세요. 이미 받아 둔 파일이 있으면 다시 받지 마세요.
   - find_company(회사명): 이름이 비슷한 회사 후보를 최대 10개 돌려줍니다. 상장사를 먼저 보여 주세요.
   - get_company(corp_code): 기업 개황 (company.json)
   - get_disclosures(corp_code): 최근 90일 공시 목록 (list.json) — 공시명, 접수일, 원문 링크
   - get_financials(corp_code, 연도): 단일회사 주요계정 (fnlttSinglAcnt.json, 사업보고서) — 매출액, 영업이익, 당기순이익, 자산총계, 부채총계, 자본총계
   - status 가 000 이 아니면 쉬운 한국어로 안내해 주세요. (010 미등록 키, 013 데이터 없음, 020 요청 한도 초과)
   - 같은 조회를 반복하면 다시 부르지 않도록 결과를 잠시 저장(캐시)해 주세요.
2. 화면에서 회사명을 입력하면 후보 목록이 나오고, 하나를 고르면 기업 개황 · 최근 공시 · 최근 2개년 재무 표(부채비율, 전년 대비 증감률 포함)를 미리 볼 수 있게 해 주세요. 금액은 억 원 단위로 보여 주세요.
3. 끝나면 "현대캐피탈" 과 "삼성전자" 로 직접 테스트해 보고 결과를 요약해 알려 주세요.

보고서 작성 에이전트 완성하기

이제 Claude가 DART 도구를 직접 골라 쓰게 합니다. 사용자는 주제만 주고, 에이전트가 계획 → 자료 수집 → 작성 → 자체 점검을 거쳐 근거 달린 보고서를 냅니다.

단계에이전트가 하는 일쓰는 것
1 계획주제를 읽고 어떤 회사의 어떤 자료가 필요한지 정한다Claude API
2 수집회사를 찾고 개황·공시·재무를 조회한다dart_api.py
3 작성정해진 양식으로 보고서를 쓰고 출처를 단다Claude API
4 점검숫자가 수집 자료와 맞는지 다시 확인하고 고친다Claude API

6-1. 에이전트 엔진 만들기

PROMPTClaude Code · 에이전트 엔진
보고서 작성 에이전트를 만들어 주세요. Claude API 키는 .env 의 ANTHROPIC_API_KEY 를 쓰고 anthropic 파이썬 SDK를 사용합니다. 모델은 claude-sonnet-5-5 로 하되, 파일 맨 위 설정값 한 곳에서 바꿀 수 있게 해 주세요.

agent.py 를 만들고 아래처럼 동작하게 해 주세요.
1. Claude의 도구 사용(tool use) 기능으로 아래 도구를 Claude에게 알려 주세요. 실제 동작은 dart_api.py 의 함수를 그대로 씁니다.
   - find_company, get_company, get_disclosures, get_financials
2. Claude가 필요한 도구를 스스로 골라 호출하고, 결과를 보고 다시 판단하는 과정을 반복하게 해 주세요. 도구 호출은 최대 10번까지만 허용합니다.
3. 수집이 끝나면 아래 양식의 마크다운 보고서를 쓰게 해 주세요.
