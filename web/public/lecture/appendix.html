VS Code 설치·한국어 설정과 Python 설치

VS Code

  1. 아래 주소에서 Download 버튼을 누릅니다.
    BROWSERVS Code 다운로드
    https://code.visualstudio.com
  2. Windows: 설치 중 PATH에 추가와 "Code(으)로 열기" 메뉴 추가를 체크합니다.

이 교안은 한국어 메뉴 기준으로 설명합니다. 예를 들어 "파일 → 폴더 열기"가 영어 화면에서는 File → Open Folder입니다. 수업 중 헷갈리지 않도록 지금 바꿔 둡니다.

  1. VS Code 왼쪽 세로 막대에서 네모 4개 모양 아이콘(Extensions) ①을 누릅니다. 단축키는 Ctrl+Shift+X (Mac은 Cmd+Shift+X)입니다.

  4. 설치가 끝나면 오른쪽 아래에 "Change Language and Restart" 알림이 뜹니다. Restart ④를 누르면 VS Code가 껐다 켜지며 한국어로 바뀝니다.
  5. 상단 메뉴가 파일 · 편집 · 선택 영역 · 보기 · 이동 · 실행 · 터미널 · 도움말로 보이면 성공입니다.

알림이 안 뜨거나 놓쳤을 때

  1. Ctrl+Shift+P (Mac은 Cmd+Shift+P)를 누르면 화면 위쪽에 명령 입력창이 열립니다.
  2. display language를 입력하고, 나오는 Configure Display Language를 누릅니다.
  3. 목록에서 한국어 (ko)를 고르고, 다시 시작할지 물으면 Restart를 누릅니다.
영어로 되돌리고 싶을 때같은 방법으로 Configure Display Language를 열고 English (en)를 고르면 됩니다. Claude Code 패널은 언어 설정과 상관없이 한국어로 말을 걸면 한국어로 답합니다.

VS Code 화면 둘러보기: 창 구성, 터미널, PowerShell

앞으로 "탐색기에서 파일을 열고", "터미널을 보세요" 같은 말이 계속 나옵니다. 처음에 VS Code 화면이 어떤 칸으로 나뉘어 있고, 각 칸이 무슨 일을 하는지 한 번 잡고 가면 수업이 훨씬 편해집니다.

VS Code 화면은 여섯 칸입니다

칸이름비유이 수업에서 하는 일
①액티비티 바
왼쪽 세로 아이콘 줄		서랍 손잡이위에서부터 탐색기(종이 2장), 검색(돋보기), 소스 제어, 확장(네모 4개). 누르면 ② 자리 내용이 바뀝니다. 우리는 탐색기와 확장만 씁니다.
②탐색기
파일 목록		서류함지금 연 폴더(report-agent)의 파일이 보입니다. 파일을 한 번 누르면 ③에 열립니다. .env에 키를 넣을 때 여기서 엽니다.
③편집기
가운데 큰 칸		책상 위 서류파일 내용을 보고 고치는 곳입니다. 우리는 주로 읽기만 하고, 고치는 일은 Claude Code가 합니다. 위쪽 탭으로 여러 파일을 오갑니다. 탭에 ● 표시가 있으면 저장 전이니 Ctrl+S.
④Claude Code 패널
오른쪽(또는 왼쪽)		옆자리 개발자프롬프트를 붙여넣는 곳입니다. 편집기 오른쪽 위 ✻(불꽃) 아이콘으로 엽니다. 허락을 물으면 여기서 답합니다.
⑤패널 · 터미널
아래 칸		기계실 창구컴퓨터에 글자로 명령하고 결과를 보는 곳입니다. 앱 실행 주소와 오류 메시지가 여기에 나옵니다. 아래에서 자세히 설명합니다.
⑥상태 표시줄
맨 아래 파란 줄		계기판오른쪽에 Python 3.12 ('.venv')처럼 보이면 이 폴더 전용 Python이 선택된 것입니다. 오류·경고 개수도 보입니다.
칸이 사라졌을 때탐색기가 안 보이면 ①의 종이 아이콘을 누르거나 Ctrl+B. 터미널이 안 보이면 Ctrl+`(숫자 1 왼쪽 키). 화면이 엉망이 되면 메뉴 보기 → 모양 → 레이아웃 다시 설정(영어: View → Appearance → Reset Layout)을 누르면 처음 모양으로 돌아옵니다.

터미널이란

평소에는 마우스로 아이콘을 눌러 컴퓨터에 일을 시킵니다. 터미널은 같은 일을 글자로 시키는 창입니다. "이 폴더 파일 목록 보여 줘"를 클릭 대신 dir이라고 쳐서 시키는 식입니다. 우리 수업에서는 Claude Code가 대부분의 명령을 대신 입력하므로, 우리는 결과를 읽는 일이 많습니다.

PowerShell, 명령 프롬프트, Git Bash는 무엇인가요

터미널은 "창"이고, 그 안에서 명령을 알아듣는 "통역사"가 따로 있습니다. 통역사마다 사투리가 조금 다릅니다.

통역사어디서특징이 수업에서
PowerShellWindows 기본줄 앞에 PS가 붙습니다. VS Code 터미널을 열면 보통 이것이 나옵니다.주로 사용
명령 프롬프트(cmd)Windows 옛 방식검은 창, 줄 앞에 C:\>만 보입니다. 일부 명령이 PowerShell과 다릅니다.쓰지 않음
Git BashGit 설치 시 함께 생김Mac·리눅스와 같은 말투. Claude Code가 내부에서 씁니다.직접 쓰지 않음
zsh(터미널)Mac 기본줄 끝에 %가 붙습니다.Mac 사용자

터미널 오른쪽 위의 ∨를 누르면 통역사를 골라 새 터미널을 열 수 있습니다. 헷갈리면 PowerShell을 고르세요.

터미널 한 줄 읽는 법

TERMINALVS Code 터미널 예시 (Windows)
(.venv) PS C:\Users\user\Desktop\report-agent> _
부분뜻
(.venv)이 폴더 전용 Python 환경이 켜져 있음. 없으면 "No module named streamlit" 같은 오류가 날 수 있습니다.
PS지금 통역사가 PowerShell이라는 표시
C:\Users\user\Desktop\report-agent지금 서 있는 폴더 위치. 명령은 이 폴더를 기준으로 실행됩니다.
> 와 깜빡이는 커서"명령을 기다리는 중". 여기서 입력하고 Enter.

터미널 위쪽 버튼

＋터미널을 하나 더 엽니다. 앱이 실행 중이라 입력이 안 될 때 씁니다.

휴지통그 터미널을 끕니다. 실행 중이던 앱도 함께 꺼집니다.
^ / ×칸을 크게 하거나 숨깁니다. ×로 숨겨도 앱은 계속 실행됩니다.

launch code 메일이 안 옴스팸함 분류, 회사 메일 보안 필터스팸함 확인, 화면의 Resend code, 안 되면 개인 메일로 가입
창고 안에 폴더가 하나 더 생김폴더째 끌어다 놓음폴더를 눌러 안의 파일을 열고 ⋯ → Delete file로 지운 뒤, 파일만 다시 올리기. 또는 창고를 지우고(Settings 맨 아래 Delete) 새로 만들기
.env를 실수로 올림07장 점검 누락그 파일을 Delete file로 지우고, 그 키는 콘솔에서 즉시 삭제 후 새로 발급. 지워도 기록(커밋)에 남기 때문입니다.
uploading an existing file 링크가 안 보임README를 추가해 창고를 만듦창고 화면 Add file → Upload files로 올리면 됨
휴대폰에서 끌어다 놓기가 안 됨휴대폰 브라우저 제약PC 브라우저에서 진행
